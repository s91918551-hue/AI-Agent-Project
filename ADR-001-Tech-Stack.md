# ADR 1: Selection of Tech Stack for Basic AI Agent

## Status

Accepted

## Context

As part of the AI-Augmented Workflow course, we need to develop
a basic AI Agent.

The purpose of this project is to understand how an AI Agent works,
how Python can communicate with an AI model, and how AI-assisted
coding can be used during software development.

The project should be simple, beginner-friendly, and suitable for
an academic e-Portfolio.

## Decision

We selected the following technologies:

- Python – Main programming language
- Ollama – Local AI platform
- Llama 3.2 – Large Language Model
- Visual Studio Code – Development environment
- Git and GitHub – Version control and project sharing

Ollama was selected instead of the OpenAI API because it allows
the project to run a local AI model without requiring an API key.

## Consequences

### Advantages

- Python is easy for beginners to learn.
- Ollama allows the AI model to run locally.
- No OpenAI API key is required.
- The project can work without depending on a cloud AI service.
- The technology stack is suitable for AI-assisted coding.
- The project can be extended with additional AI features.

### Disadvantages

- Local AI responses may take more time.
- The AI model requires computer resources.
- Performance depends on the computer's hardware.
- AI-generated code may contain errors and must be checked.

## AI-Assisted Coding Compatibility

AI tools can assist with:

- Generating Python code.
- Explaining programming concepts.
- Finding and fixing errors.
- Improving code quality.
- Creating documentation.
- Suggesting future improvements.

AI-generated code will be reviewed, understood, and tested before
being included in the final project.

## Conclusion

Python with Ollama and Llama 3.2 provides a simple and practical
technology stack for developing a beginner-level AI Agent.

The selected stack is suitable for learning AI concepts and
demonstrating an AI-Augmented Workflow in an academic e-Portfolio.
