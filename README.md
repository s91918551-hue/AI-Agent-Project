# Basic AI Agent

## 1. Project Overview

This project is a basic AI Agent developed as part of the
AI-Augmented Workflow course.

The agent accepts questions from a user and generates responses
using a locally running AI model.

## 2. Objective

The main objectives of this project are:

- To understand the basic concept of an AI Agent.
- To learn how Python can interact with an AI model.
- To use AI-assisted coding during development.
- To understand the basic workflow of an AI application.

## 3. Technology Stack

- Python
- Ollama
- Llama 3.2
- Visual Studio Code
- Git and GitHub

## 4. Architecture

User
↓
Python AI Agent
↓
Ollama
↓
Llama 3.2
↓
AI Response

## 5. Features

- Accepts questions from the user.
- Generates AI-based responses.
- Runs using a local AI model.
- Simple command-line interface.
- Can be extended with additional features.
